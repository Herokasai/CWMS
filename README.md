# CWMS – Car Wash Management System

CWMS is a web-based Car Wash Management System designed to help manage car wash operations efficiently.

## 🚗 Features

- Customer registration
- Customer login
- Car wash service plans
- Washing plan information
- Contact page
- Location information
- Admin management
- Responsive website interface

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript


## 💻 Requirements

To run CWMS locally, you need:

- XAMPP
- PHP
- MySQL
- Web browser

## ⚙️ Installation

1. Download the repository.
2. Extract the ZIP file.
3. Copy the `cwms` folder into your XAMPP `htdocs` folder.
4. Start Apache and MySQL in XAMPP.
5. Open phpMyAdmin.
6. Create a database named `cwmsdb`.
7. Import `cwmsdb.sql`.
8. Open your browser and go to:

```text
http://localhost/cwms/
